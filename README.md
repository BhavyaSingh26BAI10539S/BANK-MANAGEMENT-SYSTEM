# BANK-MANAGEMENT-SYSTEM

Description
This project is a Python-based Bank Management System that provides a simple menu-driven interface for managing basic banking operations. It includes separate Admin and User login systems.
Users can view and update account details, check loan status, deposit and withdraw money, view their passbook, submit feedback, and visualize loan trends. Admins can create new accounts, manage loan records, update loan status, view customer feedback, identify loan defaulters, and monitor loans taken over the years.
The project uses Python dictionaries and lists to store account, loan, feedback, and transaction data, so no MySQL database is required. Matplotlib is used for graphical representation of loan data.

Requirements
Python 3.x
Matplotlib

Installation
Install Python 3.x on your computer.
Download or clone this repository.
Open the terminal in the project folder.

Install the required external library using:
pip install matplotlib

How to Run
Run the Python file using:
python bank_management_system.py

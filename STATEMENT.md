Bank Management System

The Bank Management System is a Python-based project developed to simulate basic banking operations through a simple menu-driven interface. The system provides separate Admin and User modules for managing customer accounts, transactions, loans, feedback, and passbook records.

The project is implemented using Python dictionaries and lists instead of MySQL, making it lightweight and easy to run without requiring an external database. It also uses Matplotlib for graphical representation of loan data over different years.

Key Functionalities
Admin and User authentication
Customer account creation and management
Account information updates
Deposit and withdrawal operations
Transaction and passbook management
Loan data management
Loan status updates
Loan defaulter identification
Customer feedback management
Loan trend visualization
Technologies Used
Python 3
Python Dictionaries and Lists
Matplotlib
random module
datetime module
Purpose

The main purpose of this project is to demonstrate the practical application of Python programming concepts in developing a real-world banking system. It combines functions, loops, conditional statements, data structures, input validation, authentication, transaction handling, and data visualization into one integrated application.

This project is developed as an academic Python project and can be further enhanced by adding a graphical user interface, permanent database storage, stronger authentication, and additional banking features.
